# v0.1.0: project skeleton

Status: Released (2026-07-12), superseded by [v1.0.0](./v1.0.0.md) · Release notes: [changelog/v0.1.0.md](../../changelog/v0.1.0.md)

This was the starting point: the repository and the decisions behind it. No feature worked end to end.

## Contents

| Area | Status | What existed |
|---|---|---|
| Repository | ✅ | Root configuration, `.gitignore`, scripts for Windows and POSIX |
| Backend | 🧪 | FastAPI skeleton, Dockerfile, route stubs for core modules |
| App | 🧪 | React Native skeleton and configuration templates |
| Local stack | ✅ | Multi-service `docker-compose.yml` |
| Docs | ✅ | First product and architecture docs, draw.io diagrams (architecture, Docker, ERD) |

## What carried forward

- Docker-first development, which is still a hard rule.
- One app for every device.
- The multi-tenant goal.

The early diagrams assumed Traefik, Celery, MinIO and a separate web dashboard. v2.0.0 does not use them, and the diagrams were redrawn.
