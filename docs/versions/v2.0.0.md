# v2.0.0: production-grade multi-tenant POS

Status: **Current**, released 2026-10-24 · Previous: [v1.0.0](./v1.0.0.md) · Release notes: [changelog/v2.0.0.md](../../changelog/v2.0.0.md)

A rebuild for Indian shops of every size, from a one-counter kirana to large restaurants, cafés, cloud kitchens and retail. One Expo codebase runs on desktop web (PWA), Android and iOS. The backend is FastAPI, PostgreSQL with Row-Level Security, and Redis.
- **Database:** 38 tables, migrations 0001–0062 (one per table). Every table and column: [Tallyko_Database_ERD.drawio](../diagrams/Tallyko_Database_ERD.drawio).
- **Tests:** 180 backend, 310 app.

## Data & migrations

- 38 tables:
  - 13 global (platform);
  - 25 business tables with Row-Level Security: 21 through their own `tenant_id`, 4 through a parent row.
- Migrations `0001`–`0062`, forward-only within a release.
- `0059` removes DELETE on business records from the app role. It also makes `audit_logs` and `product_versions` append-only.

## Upgrade notes

1.x databases are detected by `manage.py`. In development, recreate them with `python manage.py fresh --seed`. The old code and migration chain are in `legacy/`. Back up first with `scripts/backup_db.*` if the data matters.
