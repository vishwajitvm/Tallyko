# v1.0.0: first working POS (prototype)

Status: Released (2026-07-12), superseded by [v2.0.0](./v2.0.0.md) · Previous: [v0.1.0](./v0.1.0.md) · Release notes: [changelog/v1.0.0.md](../../changelog/v1.0.0.md)

v1.0.0 replaced the placeholders with real screens and API calls. It proved the product flow but was not production-grade:
- tenant isolation relied on application code only;
- AI menu generation and printing were simulated;
- there was no offline billing, no roles and no GST management.

The code and its migration chain are archived in `legacy/`.

## Why it was replaced

v2.0.0 rebuilt the schema and app because the v1 data model had several gaps that could not be fixed in place:
- no Row-Level Security;
- prices could come from the client;
- no client-generated order ids for offline replay;
- one migration chain mixing many tables.

To upgrade, see [v2.0.0 → Upgrade notes](./v2.0.0.md#upgrade-notes).
